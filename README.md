## Описание

Учебный интернет-магазин PunanovStore — та же предметная область, что и в КР №1
(бутерброд, бычок-осеменитель, водка «Пять Озёр»), но это **отдельная реализация на Bootstrap**,
а не адаптация кода КР №1. Сайт состоит из главной страницы, каталога с фильтрами,
страницы товара, формы заявки и страницы контактов. Каталог расширен до 6 товаров в 4 категориях.

## Подключение Bootstrap

В проекте Bootstrap подключён **локально**, без CDN. Файлы фреймворка взяты из официального
архива `bootstrap-5.3.8-dist.zip` (https://getbootstrap.com/docs/5.3/getting-started/download/)
и размещены в папке `vendor/bootstrap/`.

Используются:

- `vendor/bootstrap/css/bootstrap.min.css` — подключается в `<head>`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — подключается перед `</body>` (bundle уже содержит Popper,
  нужный для dropdown).

Порядок подключения стилей на каждой странице:

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="vendor/bootstrap-icons/bootstrap-icons.min.css">
<link rel="stylesheet" href="css/custom.css">
```

`custom.css` подключается **после** Bootstrap: при одинаковой специфичности побеждает правило, объявленное
позже, поэтому собственные стили могут переопределять переменные и правила фреймворка.

JavaScript:

```html
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
<script src="js/main.js"></script>
```

**CDN или локально?** CDN-ссылка грузит файлы с внешнего сервера (нужен интернет, но файлы могут быть
уже в кэше браузера). Локальное подключение хранит фреймворк в репозитории: сайт работает без доступа
к CDN, версия зафиксирована, GitHub Pages отдаёт всё с одного домена.

## Bootstrap-сетка

- `container` — ограничивает ширину содержимого на всех страницах; hero и подвал растянуты на всю ширину
  фоном, а содержимое внутри них — в `container`;
- `row` + `col-*` — все блоки построены на 12-колоночной сетке;
- адаптивные колонки:
  - популярные товары: `col-12 col-md-6 col-lg-4` (1 → 2 → 3 в ряд);
  - преимущества: `col-12 col-sm-6 col-lg-3` (1 → 2 → 4);
  - категории: `col-6 col-md-3` (2 → 4);
  - каталог: боковая колонка `col-12 col-lg-3` + товары `col-12 col-lg-9`, внутри — `col-12 col-md-6 col-xl-4`;
  - товар и заявка: `col-12 col-lg-6` / `col-12 col-lg-8` + `col-12 col-lg-4`;
  - поля формы: `col-12 col-md-6`;
- промежутки: `g-2`, `g-3`, `g-4`, `g-lg-5`.

## Реализованные компоненты

Обязательные:

- `navbar` — единая навигация на всех страницах, логотип, активный пункт, мобильное меню (`navbar-toggler` + `collapse`);
- `card` — карточки товаров, преимуществ, категорий, контактов, обёртка формы;
- `btn` — `btn-primary`, `btn-outline-primary`, `btn-outline-secondary`, `btn-light`, `btn-lg`, `btn-sm`;
- `badge` — «Хит», «Новинка», «Скидка», «18+», счётчик найденных товаров, статусы в таблице;
- `alert` — информационные (`alert-info`), предупреждение (`alert-warning`), успех отправки (`alert-success`), закрываемый alert в каталоге;
- `modal` — «Быстрая заявка», открывается из навигации и из каждой карточки товара;
- `form-control`, `form-select`, `input-group`, `form-check` — форма заявки и форма в модальном окне.

Дополнительные:

- `carousel` — слайдер товаров в hero-блоке;
- `tabs` (`nav-tabs` + `tab-content`) — «Описание / Характеристики / Доставка» на странице товара;
- `accordion` — FAQ на странице товара и «Доставка и оплата» на странице контактов;
- `toast` — уведомление после отправки заявки;
- `offcanvas` (`offcanvas-lg`) — фильтры каталога: сбоку на больших экранах, выезжающая панель на телефоне;
- `dropdown` — меню «Категории» в navbar;
- `breadcrumb` — хлебные крошки на внутренних страницах;
- `list-group` (в т.ч. `list-group-numbered`) — шаги заказа, способы доставки;
- `table` (`table-striped`, `table-bordered`, `table-hover`, `table-responsive`) — характеристики и график работы;
- `form-switch`, `form-check-inline` (radio), `form-text`, `invalid-feedback` / `was-validated`.

## Форма заявки

Форма на `order.html` содержит: имя, e-mail, телефон (`input-group` с префиксом +7), товар или тему заявки
(`form-select`), количество, способ получения (radio), адрес (только для курьера), комментарий и
согласие на обработку данных (`form-check`).

- у каждого поля есть `label` и `name`;
- обязательные поля помечены `required`, для телефона задан `pattern`, для имени — `minlength`;
- используется Bootstrap-валидация: `novalidate` + класс `was-validated` + `invalid-feedback`;
- на телефоне поля идут в одну колонку, с 768px — в две.

## Самостоятельные доработки

1. **Локальное подключение Bootstrap** из `vendor/bootstrap/` (и Bootstrap Icons из `vendor/bootstrap-icons/`) — без CDN.
2. **Новая страница `contacts.html`**: карточки контактов, таблица графика работы, accordion «Доставка и оплата».
3. **Каталог с фильтрами**: поиск по названию, категории (`form-check`), диапазон цены (`input-group`),
   переключатель «Только со скидкой» (`form-switch`), сортировка (`form-select`), счётчик найденных товаров,
   пустое состояние с кнопкой сброса. Фильтры работают без перезагрузки страницы.
4. **Фильтры в offcanvas** на экранах < 992px (`offcanvas-lg`), на десктопе — закреплённая боковая колонка.
5. **Сквозной сценарий заказа**:
   - меню «Категории» и плитки на главной ведут в каталог с уже включённым фильтром (`catalog.html?category=farm`);
   - кнопка «Заказать» в карточке открывает модальное окно с уже выбранным товаром;
   - «Подробнее» открывает `product.html?id=...` — одна страница товара показывает любой из 6 товаров;
   - на странице товара выбирается количество, «Оформить заявку» передаёт товар и количество в форму
     (`order.html?product=vodka&qty=3`);
   - после отправки — alert с именем и товаром и toast-уведомление.
6. **Улучшенная форма заявки**: количество, способ получения, поле адреса появляется только для курьера
   и становится обязательным, счётчик символов комментария, кнопка «Очистить», боковая колонка со
   шагами заказа.
7. **Дополнительные компоненты**: carousel, tabs, accordion, toast, offcanvas, dropdown, breadcrumb, list-group.
8. **Расширенный каталог**: 6 товаров, 4 категории, старая цена при скидке, метка «18+».
   Иллюстрации пельменей, курицы и самовара нарисованы в SVG, фотографии из КР №1 пережаты в WebP
   (≈ 1,2 МБ → 50 КБ для бутерброда).
9. **custom.css** (≈ 300 строк, разбит на разделы):
   - фирменный цвет из логотипа задан через переменные Bootstrap (`--bs-primary`, `--bs-primary-rgb`,
     `--bs-btn-*`), а не переписыванием компонентов;
   - hero с градиентом, полоса призыва к действию, подчёркивание заголовков секций;
   - карточки товаров с одинаковой областью изображения (`aspect-ratio: 4 / 3` + `object-fit: contain`)
     и эффектом при наведении;
   - тёмный подвал, видимый `:focus-visible`, ссылка «Перейти к содержимому» для клавиатуры;
   - `prefers-reduced-motion` отключает анимацию карточек.
10. **Адаптивность и доступность**: проверено на 375, 768, 1024 и 1440px — нет горизонтальной прокрутки;
    на узких экранах кнопки растягиваются на всю ширину; у иконок `aria-hidden`, у изображений осмысленные
    `alt`, у навигации и секций — `aria-label`/`aria-labelledby`.

## Как проверить проект

1. Открыть `index.html` (или ссылку GitHub Pages) — работают carousel и меню «Категории».
2. В DevTools включить ширину 375px — меню сворачивается в кнопку и раскрывается.
3. На главной нажать «Ферма» — откроется каталог с отмеченным фильтром «Ферма» (2 товара).
4. В каталоге включить «Только со скидкой» — появится сообщение «ничего не найдено»; нажать «Сбросить фильтры».
5. Сменить сортировку на «сначала дороже» — первым станет бычок.
6. Нажать «Заказать» у курицы — модальное окно откроется с выбранной курицей; нажать «Отправить»
   с пустыми полями — появятся ошибки; заполнить — окно закроется, появится toast.
7. Нажать «Подробнее» у водки — откроется `product.html?id=vodka` со старой ценой и меткой 18+;
   переключить вкладки, раскрыть accordion, увеличить количество и нажать «Оформить заявку».
8. На `order.html` товар и количество подставятся сами; выбрать «Курьер» — появится обязательное поле адреса.
9. Проверить `contacts.html`.

## Контрольные вопросы (кратко)

- **container / row / col-*** — ограничение ширины, строка сетки (flex-контейнер с отрицательными отступами),
  колонки с шириной в долях от 12.
- **g-*, gx-*, gy-*** — промежутки между колонками: оба направления / только горизонтальные / только вертикальные.
- **Bootstrap JS Bundle** нужен для `collapse` (мобильное меню), `modal`, `dropdown`, `accordion`, `carousel`,
  `tab`, `toast`, `offcanvas`.
- **Открытие модального окна** — атрибуты `data-bs-toggle="modal"` и `data-bs-target="#orderModal"`;
  закрытие — `data-bs-dismiss="modal"`.
- **Локальное подключение** требует файлы `bootstrap.min.css` и `bootstrap.bundle.min.js`.
